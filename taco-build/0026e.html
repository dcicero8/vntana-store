3Upload, QA & Approval

When the family is built, self-QA against this checklist first, then upload to the VNTANA platform as a Draft and notify VNTANA for review. Do not mark anything final. VNTANA does the final approval.

Shared render toolkit

Use VNTANA’s shared toolkit so cameras, lighting, and the render environment are identical on every asset. Always download the latest version.

  • Blender template: download the latest version. It has Taco's 9 cameras (01_Front-Top-Left_Hero to 09_Detail) and the render settings. Copy the cameras, World and color settings into your file; delete any old cameras.
  • Studio HDRI: download the latest version, pack it into your file, strength 1.0. Color: ACES 1.3, exposure 1.0. No extra lights.

Pre-delivery QA (check every item before uploading)

  • All deliverables present per variant: GLB (exported from the delivered .blend), packed .blend, parts manifest CSV, Substance Painter project (.spp), self-check renders (hero + 4K metal close-up).
  • One mesh per serviceable part at scene root. No mega-part, no empty wrappers. GLB has the same meshes, names and materials as the .blend.
  • All internal parts kept. Nested shells have 2mm clearance.
  • Every mesh has a real part name (or a flagged catalog name). Fasteners grouped logically.
  • Upright, grounded (bottom at Z = 0), origin bottom-center, real-world meters. No scale on any object (transforms applied).
  • glTF PBR metal/roughness, textures embedded. Separate materials from the signed-off library, named as in the library. No single baked atlas for the whole product.
  • Single 0 to 1 UV per material, seams hidden.
  • Faceplate / labels / screens are textures, artwork version confirmed.
  • Cameras, World and color settings from the latest VNTANA template (9 cameras, Studio HDRI at 1.0, ACES 1.3, exposure 1.0). Real-world size, checked against Taco's CAD.
  • Renders smooth at 4K. Source artifacts flagged in notes, not reproduced.
  • All variants share the same body geometry; only the noted differences change.

Upload to VNTANA platform

  • Pipeline: Preserve Meshes + UVs. Keep the model where it is (no recentering, no rescaling).
  • Turn Draco OFF.
  • Save as Draft. Do not publish.
  • Fill the parts manifest so the platform part list matches your named meshes.
  • Upload the finished GLB, packed Blender file, and parts manifest as a new version of the original platform asset (the same asset the Platform link points to), not as a brand-new asset.
