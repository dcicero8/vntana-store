4Construction system

Model only what is visible (confirmed with Edgar, Oct 14). The first three are visible geometry we model and texture, external plastic, visible metal liners, carapace, plus nameplate, Wilbert logo plate, and handles. The last three (tagged Not needed for 3D) are internal detail, inside plastic liners, butyl/seals, bonding, which are never shown unless we do a cross-section, so they are out of scope for modeling. Full cross-sections and per-vault exploded views are in the reference PDF.

External plastic liners

  • Tribute Cover
  • Tribute Base Assembly (2 side + 2 end, epoxy joints)
  • Wilbert Bronze Base Liner

Metal liners

  • Metal Cover — one piece
  • Metal Base — bottom plate + 2 side + 2 end + 4 corner (interlocked + taped)
  • Metals: stainless, bronze, copper

Carapace (personalization top)

  • Plastic or metal (vault defines)
  • Emblems, engravings, photos, images, canvas

Internal plastic liners Not needed for 3D

  • Dome Cover
  • Modern Cover
  • Flat Bottom Base
  • Standard Base
  • Speed Bump Base

Seals Not needed for 3D

  • Tongue & Groove with butyl (all plastic-lined)
  • Flat (unlined only)

Bonding Not needed for 3D

  • UNIDEX — concrete/plastic, metal/plastic
  • 2-part adhesive — carapace to cover
  • Urethane caulking — metal base surround

53D modeling scope — what we build vs skip

Confirmed with Edgar (Oct 14): model only what a shopper can see, even with the lid off. Scope is set by mesh / variant count, not open configuration.

We model (visible)

  • External plastic shell — cover + base
  • Visible metal liners — metal cover liner, metal base liner (Bronze, Triune)
  • Outer metal cover (Bronze / metal vaults)
  • Carapace (plastic or metal)
  • Nameplate (molded, fixed position) + Wilbert logo plate
  • Handles — fixed per vault; one geometry, recolored to the finish
  • Base pattern window + half-moon lift notches (Bronze: corner indents)
  • Emblems / cover prints — 2D decals

We do NOT model (internal)

  • Inside plastic liner (never visible)
  • Butyl seal between cover and base Chris?
  • Bonding / adhesive / caulking
  • Concrete interior, casket rest, record tube (hidden)
  • Manufacturing stamp codes
Flag: the butyl and inner liners are only needed if Chris / Casey want a construction / cutaway view. Default is no, so they stay out.
