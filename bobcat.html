The problem

The loader is a heavy model

At roughly 12 MB it loads on every page view, which slows the experience. Two fixes: make the model itself lighter, and only load it when the visitor asks. The lighter model is ours to deliver; the deferred load is a page-side pattern that works with the standard embed.

Option 1

Serve a lighter model

The fastest win, and it's on us. Same machine, re-optimized to about half the size so even the loaded experience is quick, no CAD rebuild. Load both side by side, the lighter build shows up noticeably faster and looks the same.

How do you do it

We give you an updated optimization preset tuned for the web, a polygon cap plus 1K textures (visually identical to 2K at this scale) with Draco and KTX for mobile stability. Re-run your assets through it and they come out about half the size. Same embed URL, no page-code change.

Option 2

Click to load, in place

The page ships a lightweight preview image. The 3D viewer loads right where the image was, only after the visitor clicks, behind a branded loading screen while the model streams in.

  • Zero 3D weight on initial page load
  • Stays inline, no layout shift or new window
  • Branded loading screen while the model streams
How do you do it

Page-side, about 15 lines. Ship the preview image, then swap in the viewer on click:

<div id="s86"><img src="s86.jpg"><button id="go">View in 3D</button></div>

document.getElementById('go').onclick = () => {
  document.getElementById('s86').innerHTML =
    '<iframe src="EMBED_URL" allow="xr-spatial-tracking; fullscreen"></iframe>';
};
Option 3

Preview, then pop out

The product page shows only the static preview. A button opens the 3D in a focused pop-out over the page, and the model loads at that moment. Closing it returns to the page and unloads the viewer.

  • Product page stays completely static and fast
  • 3D gets a large, focused stage when opened
  • Closing unloads the viewer, nothing lingers
How do you do it

Same idea, but the button opens a modal and injects the viewer there, then clears it on close so nothing lingers:

openBtn.onclick  = () => modal.innerHTML = '<iframe src="EMBED_URL" ...></iframe>';
closeBtn.onclick = () => modal.innerHTML = '';   // unloads the viewer
