Bobcat · S86 Load Options
3D load strategy

Keep the page fast, load the S86 only when the visitor asks.

The loader is a large model, so loading it on every page view slows the experience. These are three ways to defer that cost so the product page stays instant, and the visitor decides when to bring the 3D in. Nothing on this page loads a 3D model until you click.

Option 1

Click to load, in place

The page ships a lightweight preview image. The 3D viewer loads right where the image was, only after the visitor clicks. A branded loading screen fills the gap while the model streams in.

  • Zero 3D weight on initial page load
  • Stays inline, no layout shift or new window
  • Branded loading screen while the model streams
Option 2

Preview, then pop out

The product page shows only the static preview. A button opens the 3D in a focused pop-out over the page, and the model loads at that moment. Closing it returns to the page and unloads the viewer.

  • Product page stays completely static and fast
  • 3D gets a large, focused stage when it is opened
  • Closing unloads the viewer, nothing lingers
Option 3

Serve a lighter model.

The two options above defer when the model loads. This one reduces how heavy it is, so even the loaded experience is faster. No rebuild of the CAD required, the same source asset is run through a lighter optimization profile, or split so the page loads a lean base and pulls detail only when needed.

Lighter optimization profileRe-optimize the existing loader to a smaller target (fewer internals, tighter mesh and texture budget) for the web view.
Lean base + detail on demandLoad a lightweight base model first; pull heavier sub-assemblies (internals, attachments) into a separate asset only when a visitor drills in.
Two versions, one embedServe a low-res version by default and swap to the full-res build for the users who want it, using variants.
Good to know

Options 1 and 2 need no custom viewer.

Click-to-load and the pop-out are built around the standard embed, they are just page-side patterns for when the embed is inserted, so they work with what Bobcat has today. The branded loading screen and lighter LOD builds are the optimization side. The custom (NPM) viewer is only needed for the deeper interactions (custom hotspot styling, guided camera tours, attribute-driven translations).
